The NUMU theme editor (V3) lets you customize your storefront with sections and settings,
with a live preview — no code required.

## Steps
1. Go to **Online Store → Themes → Customize**.
2. **Add a section** (for example a hero banner, featured products, or testimonials).
3. Edit the section's **settings** (text, images, colors) and watch the live preview update.
4. Drag sections to reorder them.
5. Click **Publish** when you're happy.

## Notes
Every change is **versioned**, so you can restore a previous version at any time. The default
theme for a new store is **luxury-minimal**, and you can switch themes from the Themes screen.
